# Security policy

## Supported versions

Only the newest release receives security fixes. Beta releases are test software and may change without notice.

## Reporting a vulnerability

Please do not publish an exploitable security issue in a public GitHub issue. Use GitHub's private vulnerability reporting feature for this repository. Include the affected version, macOS version, steps to reproduce, and any relevant logs with personal information removed.

Reports will be acknowledged when the maintainer is available. This is a personal project and does not promise a particular response or repair time.

## Sensitive information

Do not include account cookies, authentication tokens, downloaded private media, signing certificates, passwords, or personal file paths in a report.
