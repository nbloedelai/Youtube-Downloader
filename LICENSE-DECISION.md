# License decision required

No license has been selected for the original Swift app code and artwork. The copyright owner must make this decision before describing the repository as open source.

## Common choices

- **MIT:** permits use, modification, and redistribution, including commercial use, while preserving the copyright and license notice.
- **GPL-3.0:** permits use, modification, and redistribution, while requiring distributed derivative works to provide source under GPL-3.0.
- **All rights reserved:** allows people to view the public repository through GitHub but grants no general permission to copy, modify, or redistribute the original app code.

After choosing, replace this file with a root file named `LICENSE` containing the complete, unmodified license text and the correct copyright name and year. Keep third-party licenses under `ThirdParty/Licenses`; the app's license does not replace them.
